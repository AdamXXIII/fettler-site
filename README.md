# Fettler redesign: prototype

A design prototype of a redesigned fettler.co.uk for Fettler Design (Mike's wooden light shades, Newcastle). It is **not the live shop**: the basket lives in your browser, nothing is sent and nothing is charged.

**Status: draft.** Built with Claude from design decisions made by Adam. Not yet reviewed in full, not yet seen by Mike, and no tests with people have been run. Space tags, returns wording and some copy are placeholders until Mike confirms them.

The hero room is a 3D scene whose lighting was baked in Blender. The pull cord switches between daylight and evening. Photos of the shades are Mike's own, as on fettler.co.uk.

Search engines are asked not to index these pages.
